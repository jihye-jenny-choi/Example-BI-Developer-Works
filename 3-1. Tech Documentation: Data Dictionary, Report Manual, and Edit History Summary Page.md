#### Background/ Problem Defined<br>
나는 일을하면서 우리가 직시하고있는 문제들중의 부재가 tech doc이라는것을 경험하게 되었다.
일을하면서 주로 생기는 문제, 고객들로부터 자주 받는 문의들, debugging할때 investigate할때 시간이 오래걸리는 부분등 계속 반복이되는 문제들이 많았는데 이것들을 애초에 좋은 tech doc 체계를 해놓으면 많을것을 미리 방지할수있다고 생각하여,
무조건 필요하고 문제들을 미리 방지할 만한 중요한 정보를 담은 체계적인 문서프로세스를 구축하기위해 내 나름대로 연구를 하였다.
그리하여 고안해낸 방법이, end-user들에게 리포트에 관련한 supporting doc을 제공하는 것이다. 
Supporting doc의 구성은 이러하다. Data Dictionary, Report Manual, and Edit History.
