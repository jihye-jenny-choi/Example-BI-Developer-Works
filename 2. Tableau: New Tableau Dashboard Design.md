# Designing New Dashboard Layout
#### Background/ Problem Defined
This section of the depository walks you through the design of the Tableau dashboard layout. I noticed that users value the aesthetic aspect of the product since it is the first thing they notice about the product and it forms the impression about the company image and the image of the quality of the product. I believe that appealing product design also reflects the level/ sense of our understanding of utilizing visualizations.
<br><br>
Reflecting on my belief described above, I was inspired to elevate the existing dashboard layout style. The existing style was basic and functional. A blue background banner was the standard design located at the top of the report and it contained a report title. The company logo and a set of filters were also parts of the components of the banner as shown in <i>'Illustration 2-1'</i>. (A set of filters lets users view the same data more dynamically.) 
<br><br>
At that time, there were no specific guidelines for the dashboard layout and each developer followed rough layout ideas referring to the report layout of the production reports published in Tableau Server. Therefore, I noticed the layout of the dashboards developed was slightly different from report to report and not consistent. Although many of them share the cohesive dashboard layout styles, there were also a handful number of reports with variations of layout styles. For these reasons, I found designing an official dashboard style in a more appealing design as an area for improvement.
<br><br>
#### Solution Provided
I re-designed the dashboard layout style twice. The first time I developed it using Figma, the online UI/UX platform, and the layout design is currently used in production Tableau reports. 
<br><br>
The second time I designed the dashboard layout was in partnership with my colleague with a graphic design background. I led the re-design process to determine the various types of report structure, the most suitable visualization type per information, and color code rules. Reflecting on the analysis of the report structure, the most suitable visualization type, and color code rules, my colleague designed the layout style using graphic design tools. This layout design developed has not been implemented yet given that the transition to the new layout style for all 360+ reports is a huge change in the back end and it's a long-term project. However, we’re consistently looking to develop new ways to improve our system in place.
